Intel® Distribution for GDB* User Manual

The Intel® oneAPI GDB* user manual is an extension of the Debugging with GDB: the GNU Source-Level Debugger manual. It includes detailed information about the features that have been added to the Intel Distribution for GDB (aka gdb-oneapi), especially for debugging C++/SYCL applications that are deployed on an Intel GPU.

Intel GDB User Manual Formats

The reference document is available in three formats: single-page HTML, multi-page HTML and PDF. All three contain the identical information in a different format. The multi-page HTML loads the fasted and is convenient for searching words the table of contents. The single-page HTML can be slow to load and is best used for finding specific words throughout the entire document. The PDF version contains the most concise formatting and also can be slow to load. The PDF is best used for printing specific pages.

Intel Distribution for GDB Reference Sheet

The Intel oneAPI GDB reference sheet is a one page "cheat sheet" that can be used as a quick reference of frequently used gdb commands. It includes those that have been modified to support debugging C++/SYCL applications that are deployed on an Intel GPU. This "cheat sheet" is only available in the PDF format.
